# 🐅 EcoVision

### AI-Powered Wildlife Camera Trap & Monitoring Dashboard

An intelligent wildlife monitoring system that combines IoT-based motion detection, Computer Vision, and Artificial Intelligence to automate wildlife image capture and animal identification.

**Technologies:** React.js, TypeScript, Python, FastAPI, YOLO11n, OpenCV, Raspberry Pi Zero W, PIR Sensor, Supabase & PostgreSQL

**Key Features:**
- 🐾 PIR-triggered wildlife image capture
- 🤖 AI-based animal detection using YOLO11n
- 📸 Automated wildlife image processing
- ☁️ Cloud-based image and detection storage
- 📊 Interactive wildlife analytics dashboard
- 🗺️ Camera trap monitoring and detection history
