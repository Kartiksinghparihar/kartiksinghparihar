# 🐅 EcoVision

### AI-Powered Wildlife Camera Trap & Monitoring Dashboard

An intelligent wildlife monitoring system combining IoT-based motion detection, AI-powered animal identification, and cloud-based wildlife analytics.

**Technologies:** React.js, TypeScript, Python, FastAPI, YOLO11n, OpenCV, Raspberry Pi Zero W, PIR Sensor, Supabase & PostgreSQL

**Key Features:**
- PIR-triggered wildlife image capture
- AI-based animal and species detection
- Automated image processing using YOLO11n
- Cloud-based wildlife image and detection storage
- Interactive analytics and monitoring dashboard
